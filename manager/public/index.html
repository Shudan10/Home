Open it

Jellyfin

Your own media server: point it at folders of films, TV, music and photos and it fetches artwork and descriptions, remembers where you got to, and streams to phones, tablets, browsers, smart TVs, Roku, Fire TV and Kodi.

Free and entirely self-hosted, with no account and nothing phoning home. Your media stays where it is on your disk and is only ever mounted read-only, so nothing here can alter or delete it.

Apply

Changes here recreate the Jellyfin container. Your libraries and watch history are kept.

Media folders

The folders on this machine that hold your media, as full paths. Each appears inside Jellyfin under /media, named after the folder, and each is mounted read-only.

This is the path as this machine sees it, not as another computer sees it over the network. The panel checks each folder exists before saving, because Docker's own response to a path that is not there is to create an empty one and mount that.

Access

Publishing puts Jellyfin on this machine's address so anything on your network can reach it. Leave it off if you would rather it were only reachable through your domain, under Tunnel & domains.

Hardware transcoding

When a device cannot play a file as it is, Jellyfin converts it on the fly. That is expensive on the processor, and a graphics chip does it far better.

This passes /dev/dri through to the container. It has to exist on this machine, so the panel checks before saving. You still have to switch the method on inside Jellyfin, under Dashboard → Playback → Transcoding.

Updates

Jellyfin is the official jellyfin/jellyfin image rather than something built here, so updating means fetching a newer one. Your libraries, accounts and watch history live on their own volume and are kept.

Checked against Docker Hub every hour. Check for update asks right now.

Jellyfin migrates its own database on the first start after an update, so give it a minute before expecting the web page to load.

Playing from outside your home

Anyone on your home network can join with the addresses above. Friends elsewhere need your router to let the game through, because Cloudflare's tunnel only carries web pages, not games.

  1. Open your router's settings page (often 192.168.1.1 or 192.168.0.1) and find Port forwarding.
  2. Forward TCP 25565 (Java) and UDP 19132 (Bedrock) to this machine.
  3. Give friends your public address with those ports. It changes now and then unless your internet provider gives you a fixed one.

Forwarding a port puts the server on the internet. Turn on Only listed players can join under Players first, so strangers who scan for Minecraft servers cannot just walk in.

Who can join

Off: anyone who knows the address can join. On: everyone else is turned away at the door.

Java players by the name in their launcher; Bedrock players by their Xbox gamertag, without the #1234 on the end. The panel looks each one up so the server knows exactly who they are, even before they have ever joined.

Operators

Operators can use every command in the game: change the time, teleport, give items, ban people.

While the server runs, a Bedrock player has to have joined once before they can be made an operator.

Banned

Banned players cannot join, whether or not they are on the list.

Worlds on this server

The server plays one world at a time. Switching restarts it, and the world you leave is saved and stays here, ready to switch back to.

Apply

The server reads the settings below when it starts. If it is running, applying restarts it, which disconnects everyone for about a minute. The world is kept.

Minecraft's licence

Mojang only lets a server run once whoever runs it has agreed to the Minecraft End User Licence Agreement ↗. Read it, and tick the box if you agree. The server will not start until you do.

Server

LATEST moves to each new release, which is what keeps Bedrock players able to join. Pin a number like 1.21.4 to stay put, but Bedrock may stop working until you move on. Worlds only upgrade: going back to an older version is not possible.

Leave online mode on. Off lets anyone join with any name, including yours. Bedrock players sign in with Xbox either way.

Network

25565 and 19132 are what the games assume when no port is typed. Change them only if something else needs those numbers.

Gameplay

World

Distances are in chunks of 16 blocks. Lower is lighter on this machine. Spawn protection is how far around spawn only operators can build, and 0 turns it off.

Seed and world type are only used when the world is first made. To start a fresh world, uninstall without keeping the data and install again.

Console players

Consoles cannot type in a server address. With this on, the server signs in to a Microsoft account of its own and shows up in Minecraft's Friends tab for anyone who adds that account as a friend. It uses MCXboxBroadcast ↗, fetched fresh each time the server starts.

Use a spare Microsoft account, not your own. The project imitates parts of a game client, which Microsoft may treat as against its terms, and the account is shown to every player who adds it. A free new account from signup.live.com ↗ is fine and does not need to own Minecraft, but it does need an Xbox profile: sign in to xbox.com ↗ with it once and pick a gamertag before using it here.

            Remove everything
            
            
            
              Deletes every container, image, volume, network and file this stack
              created, including this panel. Docker itself is left installed, along
              with anything else you run on it.
            
            
            
              
              
            • Every file, photo and calendar stored in Nextcloud goes with it.
              • 
              
            • Base images shared with your other projects are skipped
                automatically rather than pulled out from under them.
              • 
              
            • One small helper image (docker:cli) is fetched to do
                the removing, and is the one thing left behind, because it cannot
                delete the image it is running from. Clear it with
                docker rmi docker:cli.
              • 
              
            • There is no undo, and no cancelling once it starts. The log
                appears on screen and runs until this panel is removed.
